# Shared Source Code

Optional helper code can live here.

Use this folder for reusable functions only. Final notebook code should still be clear and self-contained enough for marking.

Suggested structure:

- `shared/`: common loading, cleaning, and feature engineering helpers.
- `student_A/`: classification-specific helper code.
- `student_B/`: regression-specific helper code.
- `student_C/`: anomaly-specific helper code.
- `student_D/`: clustering-specific helper code.
