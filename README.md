# AT3 Workspace Structure

This folder mirrors the assignment structure.

## Folders

- `data/`: required CSV datasets.
- `notebooks/`: student notebook workspaces.
- `collaboration/`: meeting minutes, task board, contributions, and peer review notes.
- `submission/`: staging checklist for final Canvas upload.

## Notebook Rule

Do not modify cells marked "do not modify" in the official notebooks. Fill only the student sections and use the variables already defined by the template.

## Report Rule

Data Understanding is about assigned EDA datasets. Data Preparation is about all modelling datasets used.
