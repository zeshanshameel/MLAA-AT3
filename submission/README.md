# Submission Staging

Use this folder for the final pre-submission checklist.

Do not rely on this folder alone as the final submission unless all required artefacts have been copied here.

## Required Canvas Uploads

- All student notebooks as `.ipynb`.
- All student notebooks as editable `.pdf`.
- One final report as `.docx` or `.doc`.
- One `.zip` file containing all artefacts.

## Final Checks

- [ ] Report is under 10,000 words.
- [ ] Report is not PDF.
- [ ] Notebook PDFs are editable.
- [ ] All files use the required naming convention.
- [ ] Collaboration evidence is included.
