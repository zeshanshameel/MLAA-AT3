# Report Workspace

Use `student_sections/` for each student's draft section. The final report should be assembled into the official `.docx` template.

## Required Report Sections Per Student

- Business Understanding
- Data Understanding
- Data Preparation
- Modeling
- Evaluation
- Business Impact and Benefits
- Data Privacy and Ethical Concerns

## Anthony's Clarification

Data Understanding should cover only the assigned EDA datasets. Data Preparation should cover all datasets used in the final modelling pipeline and explain why each was used.
