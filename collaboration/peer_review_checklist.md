# Peer Review Checklist

Use this before final submission.

## Notebook Review

- [ ] Notebook runs from top to bottom without errors.
- [ ] Official "do not modify" cells were not changed.
- [ ] Student information is filled in.
- [ ] Dataset path uses `36106/assignment/AT3/data`.
- [ ] EDA includes observations, visualisations, and data quality issues.
- [ ] Data preparation explains cleaning, joins, feature engineering, and split or validation strategy.
- [ ] Modelling compares more than one reasonable approach where appropriate.
- [ ] Metrics match the problem type.
- [ ] Results are interpreted in business language.
- [ ] Limitations and risks are discussed.

## Report Review

- [ ] Data Understanding only covers assigned EDA datasets.
- [ ] Data Preparation covers all modelling datasets and explains why each is used.
- [ ] Business use case is narrow and answerable.
- [ ] Hypothesis is testable.
- [ ] Tables and graphs are labelled.
- [ ] Ethics section includes privacy, fairness, affected stakeholders, and Indigenous people risks.
- [ ] Final recommendations are concrete and tied to model results.
- [ ] References are included where external claims are made.

## Submission Review

- [ ] All `.ipynb` files included.
- [ ] All notebook PDFs are editable/copy-pasteable.
- [ ] Final report is `.docx` or `.doc`.
- [ ] Final report is not submitted as PDF.
- [ ] Zip file contains all required artefacts.
